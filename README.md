# 靈修紀錄 Spiritual Journal

手機優先的靈修紀錄網頁 App。

## 目前功能
- 今日主題／經文
- 聆聽歌曲（可選填）
- 靈修時間：5 / 10 / 15 / 20 / 25 / 30 / 自訂分鐘
- 今日電波／心得
- 月曆查看每日紀錄
- 先查看紀錄，再進入編輯
- 本月靈修天數、累計時間、平均每次
- localStorage 儲存
- 舊版 `spiritual_checkins_v1` 資料自動遷移

## 執行方式
直接以瀏覽器開啟 `index.html`，或部署到 GitHub Pages。

## GitHub Pages
建立 public repository `spiritual-journal` 後，將此資料夾內容放在 `main` branch 根目錄，並在 Settings > Pages 選擇 Deploy from a branch / main / root。
